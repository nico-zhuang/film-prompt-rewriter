# 电影感改写模式

这些模式来自本项目92条已人工初校的本地样本。它们描述的是可迁移的视觉机制，不是需要原样复制的句子。

## 情绪推进

- 结构：遮挡/前景介质 → 缓慢推进 → 对焦主体 → 微表情或视线变化 → 情绪压力增加。
- 适合：孤独、忧郁、压迫、私密情绪。
- 关键约束：前景要有实际空间作用，推进要有情绪动机，不要只写“电影感推进”。

## 环绕与梦境

- 结构：主体作为稳定中心 → 缓慢环绕 → 背景光线和逆光角度随视角变化 → 衣物/头发/环境细微运动。
- 适合：梦境、浪漫、沉浸、记忆感。
- 关键约束：主体动作保持简单，环绕速度稳定，避免同时加入复杂表演。

## 真实手持

- 结构：主体相对克制 → 手持镜头随车辆/呼吸/步伐轻微起伏 → 背景光线或街景持续掠过 → 结束在一个安静状态。
- 适合：纪录片感、城市孤独、现场感。
- 关键约束：手持不是随机抖动；要写清楚晃动的物理来源。

## 希区柯克变焦 / 空间扭曲

- 结构：主体或视线保持锚定 → 前进与焦距变化形成空间关系变化 → 背景拉伸或压缩 → 情绪转折落在主体反应。
- 适合：不安、认知改变、心理压力。
- 关键约束：把它当成一种单一镜头机制，不要再叠加快速甩镜或大幅旋转。

## 景别阶梯

- 结构：大远景交代空间 → 远景建立人物与环境关系 → 中景呈现动作 → 面部特写呈现情绪 → 极近特写强化心理细节。
- 适合：需要讲清楚空间到情绪的镜头组。
- 关键约束：这通常是多镜头/分段方案，不要把五个景别硬塞进一条单镜头提示词。

## 光影机制

- 侧逆光轮廓：主体边缘从背景中分离，适合人物、雾气、夜景。
- 水下折影：移动水面光纹投射到皮肤和环境，适合漂浮、梦境、流动情绪。
- 丁达尔光：雨后、雾中或树荫空间里的可见光束，适合安静、神秘、时间感。
- 烛光 / 低照度：保留局部高光和深暗区域，不要把所有区域照亮。

## 电影色彩

- 黑色电影：低饱和、深黑阴影、硬光、局部高光，优先写光源和阴影关系。
- 洋红与青蓝：冷背景与局部洋红光源形成色彩张力。
- 青橙：冷环境与暖肤色/暖光分离，但避免把整幅图写成纯橙蓝滤镜。
- 复古暖调：低对比、偏暖、轻微颗粒和旧镜头质感，动作仍需具体。

## 题材化风格

题材风格不是一串标签，而是多个稳定层的组合：

```text
场景/建筑 + 人物/服装 + 道具/材质 + 光影 + 色彩关系 + 构图/镜头 + 氛围 + 一个动作
```

优先选择两到四个最能识别风格的锚点，避免把所有风格词都塞进一条提示词。

## 冲突检查

- 静止主体 + 高速跟随镜头：需要说明谁静止、谁在动，否则减少其中一个。
- 低照度烛光 + 明亮均匀曝光：选择一个主光逻辑。
- 极近特写 + 巨大环境尺度：拆成两个镜头或明确先后关系。
- 慢速环绕 + 甩镜转场：拆成两条镜头。
- 纪录片手持 + 完全无抖动：改成“稳定器跟随”或保留轻微呼吸感。
