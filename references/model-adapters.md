# 模型与工作流适配

这些是保守的适配原则，不是对具体模型版本的性能保证。若用户没有指定模型，先输出通用单镜头提示词，并标记待验证部分。

## Vidu / Seedance / 即梦类中文视频模型

- 使用简洁中文，优先主体动作、镜头运动、时间顺序和结束状态。
- 一条提示词尽量只保留一个主要动作和一个主要镜头意图。
- 首尾帧工作流：把首帧负责的构图/身份与文字负责的运动分开；如果用户提供末帧，再明确从起始状态如何到末帧。
- 不要依赖大量英文摄影参数来保证效果；它们可以作为辅助，不应掩盖动作逻辑。

## Kling / Runway / Luma 图生视频

- 如果已经有参考图，提示词重点写运动、镜头、速度、环境反应和结束状态，不要重新发明人物外观。
- 连续性要求高时，拆成短镜头并用同一参考图/角色锚点。
- 复杂运动不要同时写多种镜头移动。

## Veo / Sora 类文本到视频

- 写清楚单镜头、主体、环境、事件、光线和声音（如果用户需要声音）。
- 多镜头需求用时间轴或 shot list，不要把“然后切到”放在单镜头提示词里。
- 负面约束单独列出；不要让负面词污染主叙述。

## 任何模型都适用的保守输出

```text
[格式/景别/主体/环境]。
主体从[起始状态]开始，发生[一个主要动作]，在[转折]后以[结束状态]收束。
镜头[机位/单一运动/速度/动机]，前中后景由[空间层次]建立。
光线来自[物理光源]，形成[明暗关系]；色彩以[颜色关系]为主。
保持[身份/服装/场景/关键道具]连续，避免[高风险失败模式]。
```
