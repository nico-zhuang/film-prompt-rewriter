# film-prompt-rewriter

一个面向 AI 视频创作的电影感提示词改写 Skill。

它的作用不是把提示词变长，而是把普通描述改成更容易执行的镜头方案：

- 明确主体、环境和空间关系
- 选择一个主要镜头运动
- 写清起始状态、转折和结束状态
- 补充可观察的光影、色彩、氛围和人物/材质细节
- 检查运动、光线、景别和连续性冲突
- 按 Vidu、Seedance、Kling、Veo、Runway、Sora 等工作流做保守适配
- 保留本地92条已复核电影感样本作为可追溯参考

## 安装

公开仓库：<https://github.com/nico-zhuang/film-prompt-rewriter>

下载后，将仓库中的 `film-prompt-rewriter/` 目录复制到你的 Agent Skills 目录，保留 `SKILL.md`、`references/` 和 `evals/`。如果你的宿主提供 Skill 安装命令，也可以把仓库目录作为本地路径安装。这个包只包含文本和结构化样本字段，不包含内部视频、静帧或GIF。

安装后用以下类型的请求触发：

- “把这段提示词改得更有电影感”
- “给这个画面加真实手持感”
- “把普通描述改成 Vidu / Seedance / Kling 视频提示词”
- “帮我设计一个有镜头运动、光影和情绪变化的单镜头”

## 输出

默认输出三部分：

1. 可直接复制的提示词
2. 镜头拆解
3. 本地样本依据、通用电影语言和待验证项

如果用户明确说“直接给我能复制的版本”，会压缩说明，只保留提示词和必要的短注释。

## 样本边界

`references/local-sample-library.json` 来自一组本地中文 AI 电影感视频样本，包含92条第一轮人工初校条目。它是风格和结构参考，不是任何模型的效果保证。公开包不携带原始媒体；条目中的媒体字段按策略置空，来源视频和时间只用于内部资料追溯。Skill 会区分“本地样本依据”和“通用电影语言”，不会把外部泛用词库伪装成本地验证经验。

## 质量原则

- 一镜头优先：一个主要镜头运动、一个主要事件、一个光线逻辑。
- 先写变化，再写形容词。
- 复杂多镜头需求拆成 shot plan，而不是硬塞进一段提示词。
- 不改变用户主体、身份、时代、关键道具和明确约束。
- 不承诺“必然生成成功”。
- 无法从样本确认的细节标记为待验证或待确认。
